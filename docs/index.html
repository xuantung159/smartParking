Tài liệu API cho hệ thống quản lý bãi đỗ xe · Mã nguồn · Tải đặc tả OpenAPI

Tài liệu API phase 1. Xem tài liệu không cần chạy backend. Thao tác gọi thử API đã được tắt. Nội dung lấy từ bản đặc tả lưu trong repository, có thể khác phiên bản code đang chạy. Khi cần đối chiếu, dùng /v3/api-docs của backend để cập nhật openapi.json.

Không tải được giao diện Swagger. Vui lòng kiểm tra kết nối hoặc tải đặc tả OpenAPI ở phía trên.
